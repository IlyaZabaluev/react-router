# React Sorted Lists Application

Приложение для отображения и сортировки списков (героев, локаций, эпизодов) с использованием React-Router v6 и TypeScript.

## Основные возможности

- Просмотр списков элементов (герои, локации, эпизоды)
- Сортировка по дате создания (created) в трех режимах:
  - Исходный порядок
  - По возрастанию (ASC)
  - По убыванию (DESC)
- Универсальная система сортировки, используемая во всех компонентах
- Сохранение состояния сортировки в URL

## Особенности реализации

Единая система сортировки:
Логика вынесена в отдельные модули
Используется во всех компонентах списков

Типобезопасность:
Все компоненты используют общие типы
Строгая проверка типов данных

Гибкость:
Легко добавить новые виды сортировки
Просто расширить на новые компоненты
